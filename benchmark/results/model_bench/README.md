# Local-model summarization benchmark results

Generated by `benchmark/model_bench.sh` (+ `benchmark/extract_slice.py`). Compares
small local ollama models at compacting a coding-session slice.

## Which numbers to trust
- **The deterministic FCS columns (retention/compress/fcs) are NOT a valid model
  ranker** — they punish good *selective* summaries and have format-match bugs. They
  only catch gross failures. The authoritative ranking came from a **blinded
  LLM-as-judge gut-read**, which gave:
  **qwen3.5:4b > qwen3.5:2b > granite4.1:3b > phi4-mini:3.8b > qwen2.5-coder:3b**
  (avoid qwen2.5-coder — it hallucinates completed work).

## Files
- `synthetic_factsfirst.tsv` — a synthetic-slice run (the facts-first-prompt
  calibration). The blind gut-read on real slices is the decider, not the TSVs.
